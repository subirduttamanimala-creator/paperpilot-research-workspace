# PaperPilot

PaperPilot is a local-first research reading workspace that helps students capture claims, evidence, methods, limitations, and reproducibility questions. It does not fabricate summaries or assess paper quality.

## Features
- Structured paper reading record
- Claim–evidence ledger with confidence labels
- Critical-reading and reproducibility prompts
- Browser-local research library
- Markdown export

## Run
Open `dist/index.html` in a modern browser. No build step is required.

See [PRD.md](PRD.md) for product scope and future work.
